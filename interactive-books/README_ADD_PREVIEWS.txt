INTERACTIVE BOOK LIBRARY
This section is linked from the original Glenn Beavers website homepage.
To add a free interactive preview:
1. Open Glenn Beavers Book Creator Manager V17.
2. Export "Publish Free Preview HTML".
3. Rename the exported HTML to the matching book slug, e.g. rasta-christmas.html.
4. Upload it to interactive-books/previews/.
5. Add the slug (without .html) to interactive-books/previews/available.json, e.g. ["rasta-christmas"].
6. The Read Free Preview button will appear when the website is served through GitHub Pages.
Do NOT publish a full paid reader HTML on public GitHub Pages; that would expose the entire book.
The existing bookshop pages, photographs and videos are preserved.
